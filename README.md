# Daily Order Report Dashboard

An interactive **Power BI dashboard** designed to analyze and monitor daily sales/order performance across divisions, brands, outlets, and operational KPIs.
This project helps businesses track sales efficiency, outlet performance, strike rate, and brand-wise order trends in real time.

## 🔧 Tools & Technologies Used

* Microsoft Power BI
* Microsoft Excel
* SQL
* DAX

## Key Features

* Dynamic and interactive dashboard design
* Date & Channel-wise filtering system
* KPI Cards for:

  * Total Order Value
  * Average Memo
  * Total SR Count
  * Visited Outlets
  * LPC
  * Strike Rate
  * Total Line Sold
* Division-wise performance analysis table
* Hourly order value trend visualization
* Brand/category-wise sales comparison
* Brand-wise order count analysis
* Drill-down enabled insights for better decision making

## Data Processing & Analysis

* Cleaned and transformed raw data using **Power Query & Excel**
* Extracted and managed structured data using **SQL**
* Built calculated columns and measures using **DAX**
* Created relationships and data models for accurate reporting
* Designed responsive visualizations and KPI metrics in Power BI

## Business Insights Generated

* Identified top-performing brands and divisions
* Tracked outlet visit efficiency
* Monitored sales performance by hour
* Evaluated strike rate and LPC effectiveness
* Improved operational visibility through centralized reporting

## Project Goal

The goal of this dashboard is to provide a **real-time business performance monitoring system** that enables faster decision-making and better sales analysis.
